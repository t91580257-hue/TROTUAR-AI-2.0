# TROTUAR AI 2.0 — AI-платформа

Полноценный ИИ-сервис: чат с потоковой генерацией (Ollama), генерация изображений, редактирование фотографий, анализ документов. Дизайн **Liquid Glass** из версии 1.x полностью сохранён: тёмно-фиолетовая палитра, стеклянные панели, аватар, история переписок, боковое меню и мобильная адаптация.

---

## 2. Запуск

Требуется Node.js 20+.

```bash
npm install
cp .env.example .env      # заполните при необходимости
npm start                 # http://localhost:3000
```

Режим разработки с автоперезапуском: `npm run dev`.

Для чата задайте `OLLAMA_API_KEY` в секретах хостинга. Значения по умолчанию указывают на Ollama Cloud (`https://ollama.com`, `gemma4:31b`).

## 3. Ollama Cloud — автоматическое подключение

TROTUAR AI 2.0 настроен на прямое подключение к Ollama Cloud. На телефоне или компьютере пользователя не нужно устанавливать Ollama, запускать локальный сервер или менять адрес в настройках приложения.

На сервере, где размещён backend, задайте переменные окружения:

```
OLLAMA_URL=https://ollama.com
OLLAMA_MODEL=gemma4:31b
OLLAMA_API_KEY=ваш_секретный_ключ
```

`OLLAMA_API_KEY` добавляйте только в раздел Secrets / Environment Variables панели хостинга (например, Render, Railway или VPS). Не добавляйте настоящий ключ в ZIP, GitHub, HTML или JavaScript. После сохранения переменных перезапустите backend.

В интерфейсе TROTUAR AI поля выбора провайдера, адреса и API-ключа скрыты. Сервер игнорирует попытки изменить эти параметры через пользовательские настройки и берёт их только из переменных окружения. Модель можно заменить на другую доступную cloud-модель, изменив `OLLAMA_MODEL` на сервере. Актуальный каталог: https://ollama.com/search?c=cloud.

Если ключ не задан, чат не сможет подключиться к облаку — это ожидаемо; генерация изображений и другие функции приложения работают отдельно.

## 4. Изображения: генерация и редактирование

Используется API Pollinations (проверено на актуальной документации и реальными запросами).

**Генерация (TROTUAR AI IMAGE)** — работает бесплатно, ключ не нужен:

- эндпоинт `GET https://image.pollinations.ai/prompt/...`
- лимит анонимного доступа: примерно 1 запрос в 45 секунд; при превышении приложение покажет понятное сообщение
- 8 художественных стилей, 5 пропорций, seed для повторной генерации
- готовые картинки кэшируются на сервере (`data/generated`, до 60 файлов, 7 дней) — история открывается мгновенно

**Редактирование фото** — требует ключ:

1. Получите ключ на https://enter.pollinations.ai
2. Добавьте в `.env`: `POLLINATIONS_API_KEY=sk_...`
3. Перезапустите сервер и загрузите фото в режиме «Редактор»

Эндпоинт: `POST https://gen.pollinations.ai/v1/images/edits` (OpenAI-совместимый). Фотография передаётся как data URI прямо в запросе — **нигде не сохраняется**: буфер живёт в памяти только на время обработки. Без ключа режим честно сообщает о необходимости настройки, никакой имитации работы нет.

## 5. Публикация в интернете

### Вариант A. VPS (рекомендуется для Ollama)

1. Арендуйте сервер, установите Node.js 20+ и Ollama.
2. Скопируйте проект, `npm install && npm start` (или PM2: `pm2 start server.js --name trotuar-ai`).
3. Поставьте обратный прокси с HTTPS (Caddy — автоматические сертификаты):

```
your-domain.com {
    reverse_proxy localhost:3000
}
```

### Вариант B. Cloudflare + отдельный backend

- **Frontend** (`public/`) можно разместить на Cloudflare Pages — это чистая статика.
- **Backend** (`server.js` + `src/`) требует Node-хостинга, потому что обращается к Ollama и хранит ключи. Бесплатные варианты: Render (free tier, «засыпает» без трафика), Railway trial, Oracle Cloud Free Tier (ARM VM — можно запустить и сам Ollama рядом).
- В настройках приложения укажите публичный адрес backend, либо настройте проксирование.

### Вариант C. Cloudflare Workers

Workers не умеют долго держать соединения с локальной Ollama и запускать Node-пакеты без адаптации; для этой архитектуры вариант не подходит — используйте A или B.

О честных ограничениях: бесплатный tier Render «засыпает», анонимный Pollinations ограничен по частоте, Gemini имеет дневные квоты. Обещать бесконечный бесплатный доступ нельзя — но весь стартовый сценарий (локально) полностью бесплатен.

## 6. Безопасность

- API-ключи хранятся только на сервере (`.env` + `data/settings.json`), на клиент не возвращаются даже в замаскированном виде
- серверная валидация всех входных данных: роли сообщений, длины, MIME и магических байты файлов
- лимиты: 256 КБ на JSON, 15 МБ на файлы, rate limit по IP (чат 20/мин, изображения 6/мин)
- загруженные фото пользователей не сохраняются на диск
- заголовки `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`
- Markdown рендерится через `marked` + санитизацию `DOMPurify`

## 8. Функции, требующие ключей

| Функция | Ключ | Где получить |
|---|---|---|
| Редактирование фотографий (image-to-image) | `POLLINATIONS_API_KEY` | enter.pollinations.ai |
| Резервный чат через Gemini | `GEMINI_API_KEY` | aistudio.google.com/apikey |
| Облачный Ollama | `OLLAMA_API_KEY` | провайдер Ollama-хостинга |

Всё остальное (чат с локальной Ollama, генерация изображений, PDF-анализ, голос) работает без ключей.
